## 📁 Projects

### Day 01 - Team Task Manager

A dynamic task management application where tasks can be assigned to different teams.

**Features:**
- Assign tasks to Team A, B, C, and D
- Dynamically create task elements
- Team-wise task sections
- Checkbox-based task completion
- Remove selected tasks
- Dynamic DOM manipulation
- Local Storage for task persistence

**Technologies:**
- HTML
- CSS
- JavaScript

## 📈 Daily Learning Approach

Each project is designed to be completed within a day.

The process is:

1. Learn or review a JavaScript concept
2. Plan a small project
3. Implement the project
4. Test and improve the code
5. Push the project to GitHub
6. Share my progress on LinkedIn
7. Move to the next project
